Status pills

· state in form + color, never color alone

Every deployment carries one. Shape, icon and label all encode the state so it reads without color. While anything is queued/building the page polls every ~5–10s and the pill stays visibly alive.

Queued
Waiting for a build slot. Hollow, patient — nothing has started yet.
Building · 2/4
In progress with a live step count. Blinking dot = actively polling.
Live
Running & reachable. The one the user waits to turn green.
Failed
Build didn't finish. Triangle = it never ran. Reason shown inline.
Crashed
Built fine, then died at runtime. Octagon = deployed but down.
Stopped
Preview torn down. Dashed & hollow — gone on purpose, revivable.

Not connected

· the first thing most users see — inviting, not a form

One value prop, one primary CTA, and the supported providers shown plainly. No wall of fields.
