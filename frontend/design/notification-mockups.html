Rules
• Title = agent + plain verb (started working / finished / hit a problem / needs your input). No “run”, no raw type strings.
• Second line is always the task: key + name; falls back to “Chat session” when no task.
• Pills: status (colour-coded), project, then up to 3 facts (duration, PR, cost). Cost/attempt hide behind hover on narrow widths.
• Failure reason is the plain-language message, max 2 lines. Technical details (branch, run id) stay on the Run page behind “Advanced”.
• Click opens the Run page as today.
• Unread dot kept; read items dimmed.

Data needed: store task_id, run_id, agent_name, project_name and a small meta JSON on Notification (additive migration); old rows fall back to the title.
