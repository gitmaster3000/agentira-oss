AgentIRA · Flow & UX redesign

One workflow, not two apps.

Today Agentira makes you hold two products in your head — Studio (you plan the work) and Forge (agents do the work) — joined only by a hidden grid menu. But it's one loop: plan → an agent builds → you review. This redesign collapses the seam, makes live agent activity visible everywhere, and keeps your dark Material scheme exactly as-is.

Scheme untouched — same colors & type Static hi-fi · before → after Always-on live runs Consistent inbox & buttons
DIAGNOSIS What's cumbersome today

The current shell, honestly

Five controls fight for the top bar, the left rail goes blank the moment you step outside a project, rename/delete throw native browser pop-ups, and following one task's agent means leaving for a different app. Numbers below map to the fixes.

THE FIX Four principles, applied across every screen

From two apps to one loop

One persistent rail
Projects, Plan & Build nested in a single sidebar that's always useful. No more app-switch grid.
Live, always-on
A running-agent dock + a top-bar pulse follow you everywhere. You always know what's executing.
Work in one place
A task carries its plan and its agent run as tabs. Following the agent never means leaving the task.
Consistent everywhere
One button hierarchy, one inbox with real tabs, no native pop-ups. Same patterns on every surface.
DIRECTION 1 The Unified Rail · Home Recommended spine

One sidebar replaces the project dropdown and the app-switch grid. It holds both layers at once: a shared Build section — agents, runs, runtimes, conductor — which is workspace-level and project-independent, and below it your Projects, each expanding to its own Plan (board, backlog, roadmap). Studio and Forge stay distinct layers — agents just act on any project's tasks. Home becomes a real cross-project cockpit instead of an empty rail.

Click any project. It expands to its Plan (Overview, Board, Backlog, Roadmap), and whichever was open collapses back to a single row. One project open at a time, so the rail stays short even with a dozen projects. The shared Build section above is project-independent — it never moves.

DIRECTION 2 The Work Item · Plan + Agent in one place

The deepest cut at the app-switching problem: a task is its agent run. Open a task and the live run streams right there under an Agent tab — no detour to Forge, no losing your place. Plan on the left, the agent working on the right, the same object throughout.
