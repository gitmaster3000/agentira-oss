# Loop v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agentira runs the whole scrum loop on its own project — direction → epics → tasks → dispatch → review → merged-tree tests → merge into the repo base branch → sprint review / executive summary — with no required human action.

**Architecture:** Fix and re-wire what exists. Deterministic code owns dispatch, hand-offs, merges and verification (conductor tick, workflow driver, daemon integrate). The Conductor's LLM turns own judgment (direction, epics, breakdown, assignment, summary) and act only through MCP tools. Every step writes a readable activity line.

**Tech Stack:** FastAPI + SQLAlchemy 2 + Postgres (backend), APScheduler, MCP (FastMCP), Python daemon (`agentira-cli`), React 18 + Vite (frontend), pytest + testcontainers, vitest.

**Spec:** `docs/superpowers/specs/2026-09-25-loop-v1-design.md`

## Global Constraints

- All work on branch `main-rsi`; target only the local stack; never Railway.
- Merges/pushes only to the task repo's `default_branch` (`main-rsi` for Agentira) or task branches — never a hardcoded `main`.
- Unknown / missing evidence blocks (fail closed) and is recorded with a reason.
- Prompts are configuration: instruction prose lives in `templates/**.md`, never in Python.
- Services compose, repos own SQL: new queries go in `backend/forge/repos/*` or `backend/repos/*`.
- Tests run on Postgres via the `pg` fixture (`backend/tests/conftest.py`); never SQLite.
- User-facing text is plain language; technical detail behind "Advanced".
- Run backend tests: `.venv/bin/python -m pytest backend/tests/<file> -q` (full: `-n 4`). Daemon: `cd agentira-cli && ../.venv/bin/python -m pytest tests/<file> -q`. Frontend: `cd frontend && npx vitest run <file>`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Two orgs, each with a Conductor, one managed project each — each project's turns must reach its own org's Conductor, never the other.
2. A task whose repo has no `default_branch` / no repo row — integrate must refuse with a reason, never fall back to `main`.
3. `verify_cmd` that hangs or prints megabytes — must time out, not push, and post only a bounded log tail.
4. A human manually moving a task during an agent run (e.g. back to todo) — driver must not fight it (existing rejection/demotion logic must still apply with the re-wire).
5. Queue-dry sprint planning must not fire every 10 minutes when a project is genuinely idle — once per `sprint_min_interval_hours`.

def conductor_for_org(db, org_id: str | None) -> "Profile | None":
    """The org's Conductor. There is one per org (seeded by
    get_or_create_conductor); never pick 'the first one' across orgs."""
    q = db.query(Profile).filter(Profile.name == CONDUCTOR_NAME)
    if org_id:
        q = q.filter(Profile.org_id == org_id)
    return q.order_by(Profile.created_at.asc()).first()


def primary_conductor(db) -> "Profile | None":
    """The Conductor whose settings drive the (global) schedule: the one in an
    org that actually has managed projects; else any."""
    orgs = [org for _, _, org in _managed_projects(db) if org]
    for org in orgs:
        prof = conductor_for_org(db, org)
        if prof:
            return prof
    return conductor_for_org(db, None)
```

                           text=True, timeout=timeout_s)
        out, code, timed_out = (p.stdout or "") + (p.stderr or ""), p.returncode, False
    except subprocess.TimeoutExpired as exc:
        out = ((exc.stdout or b"").decode(errors="replace") if isinstance(exc.stdout, bytes)
               else (exc.stdout or ""))
        code, timed_out = None, True
    tail = "\n".join(out.splitlines()[-_TAIL_LINES:])
    return {"exit_code": code, "duration_s": round(time.monotonic() - start, 1),
            "log_tail": tail, "timed_out": timed_out}
```
