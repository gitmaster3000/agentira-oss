# Code of Conduct

## The short version

Be decent. Assume the person on the other end is trying to build something and is
short on time.

## What's expected

- Critique the work, not the person. "This will deadlock under X" is useful; "this is
  garbage" is not.
- Accept that maintainers say no. A closed issue isn't a personal verdict — this is a
  small project with a specific shape, and scope discipline is how it stays usable.
- Be patient with people who are new to agentic tooling, self-hosting, or open source.
  Everyone was new to running agents against their own repos eighteen months ago.
- Report what you actually observed. Agentira is a tool for making agent work
  verifiable; the same standard applies to us.

## What isn't

Harassment, personal attacks, demeaning comments about anyone's identity or
background, unwelcome sexual attention, deliberate intimidation, publishing someone's
private information, or sustained disruption of discussion.

This applies in issues, pull requests, commit messages, and any other project space.

## Enforcement

Report problems to the maintainer address listed on the GitHub profile of this
repository's owner. Reports stay confidential.

Maintainers will remove, edit, or reject contributions that violate this document, and
may ban repeat or severe offenders from project spaces. Maintainers who don't follow
it themselves face the same consequences.
